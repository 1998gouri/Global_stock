# Global Stock Monitor

A global stock-monitoring application with Telegram notifications, transparent source auditing, and student-focused financial education and research.

## Initial configuration
- Market coverage target: global
- Notification channel: Telegram
- Quote polling target: 1 minute, subject to provider limits, market-data licensing, and feed delays
- Student learning content: all budget levels

## Data and reliability
A one-minute polling target does not guarantee real-time data or uninterrupted coverage. Each data source must report its provider, market coverage, timestamp, delay status, and any errors or missing fields. Do not bypass paywalls or access controls.

## Project status
Initial repository setup. Provider integrations, alert delivery, and research features are not yet implemented.
